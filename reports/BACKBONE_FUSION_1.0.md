# LAUD-UIE 1.0 · 预训练主干融合

本版采用资料库所示的 MambaCue_Backbone.zip。实现取自本地同名包，压缩包 SHA256 为 `9410002c15ad073eb1fb001d42b382f614c0de8df5e37c0a4a2655d141a59c5a`。包内主干严格加载 UIEB EMA 权重，权重 SHA256 为 `dc43cb10dd8fa4940b4f12eb0a315fe8d1c6c05f733bdd6da137c5be234239fc`。仓库包含源代码，训练者从原包取得权重。四级四方向 Mamba 编码器和三级 U-Net 解码器产生全分辨率 32 通道特征。历史完整模型另外使用先验引导、解码调制及 RGB 重建，这些模块与表中结果属于上一工作。

## 模型与实验证据

1. 在解码特征上估计逐图逐通道 RGB 偏移，同时用一个线性投影预测空间 RGB 修正并减去逐图均值。两者相加后与输入相加，再截断。整图偏移可学习场景色偏，局部修正保持零均值，避免二者重复改变全局色彩。输出层零初始化，首次前向等于输入。旧学生在单种子 LSUI 短预算验证中，中心化比等参数自由残差高 0.5711 dB。更强主干上的增益尚待验证。
2. 对原图与参考亮度顺序一致且对比度足够的位置，训练输出保持该局部顺序。直接复用现有 1、2、4 像素间距的损失。它用于保护校色后的可定位结构，增加的计算只在训练期。除了验证 PSNR、SSIM，还需观察有效结构对的覆盖率、违反率及应用测试上的 SIFT。
3. 在上述同一分解下做选择性蒸馏。单一冻结教师为本次同划分训练得到的自由残差增强器。每个训练样本分别将场景均值和零均值场向教师移动四分之一步，以各自相对参考 MSE 的下降比例估计分量效用。正效用归一化分配固定蒸馏系数，两项均无益时关闭蒸馏。这里测量输出空间的局部变化，实际参数更新和未见图像上的收益仍须验证。教师和分量选择均只在训练时使用。

## 受控实验

五组从同一份主干权重、同一种子和相同的零输出头初始化，每组训练预算相同。五组均微调主干。按固定训练/验证清单加载 RGB 256×256 整图，训练可同步水平、垂直翻转。AdamW，主干学习率 2e-5，头部 2e-4，余弦退火至 2e-6，默认 batch 1、200 轮，按验证 PSNR 保存最佳轮。预实验可以指定更短预算及固定子集，记录每组实际样本和轮数。初筛仅用开发清单。各组按以下顺序对照。

| 组别 | 训练内容 | 主要比较 |
| --- | --- | --- |
| free | 自由空间残差，逐图偏移，Charbonnier + 0.2 SSIM 损失 | 同参数的派生模型对照 |
| centered | 空间残差增加中心化 | 与 free 比较分解收益 |
| ordinal | centered 加 0.2 局部顺序损失 | 与 centered 比较结构监督 |
| fixed | ordinal 加 0.1 等权分量蒸馏 | 与 ordinal 比较固定教师监督 |
| utility | ordinal 加 0.1 效用加权分量蒸馏 | 对照 fixed 及 ordinal，检验选择监督本身 |

在模型、初始化和超参数固定后再开放正式测试。UIEB 初始化可能已接触重新划分的 UIEB 样本，正式 UIEB 测试须先核对原权重使用的图像清单。CH60（表中 C 60）与 U45 使用 UIEB 训练的候选权重。不同训练来源的权重、测试划分或指标实现需在表中注明。另记录输入尺寸、精度、硬件、延迟及计算量。三项贡献及相对完整模型的质量和效率提高均为研究假设。

运行环境为 school-gpu2 的 HVI，服务器代码、源权重、日志和各组输出放在 /home/user 下。训练入口仅实例化派生模型。

```sh
python -m luad_uie.scripts.train_backbone_fusion TRAIN_CSV VAL_CSV \
    /home/user/MambaCue_Backbone/weights/mambacue_backbone_uieb_ema.pth \
    /home/user/luad_fusion_1_0/run_01 --epochs 200
```
